# 不含剧透的视频基础简介

`video_intro` 为独立观众和接话观众提供一小段片前背景，帮助它们理解当前视频的题材、主题和初始设定。它适合解决“局部对白已经出现，但不知道这是什么类型的视频”一类问题。当前弹幕仍需要来自该时点已看到的对白或画面。

## 配置与使用

在这个视频使用的配置顶层增加一个字符串：

```json
{
  "video_intro": "这是一段介绍传统木工榫卯的科普视频，面向没有木工经验的观众。"
}
```

这是合并到现有配置的片段；供应商、观众和其他字段保持原配置。`configs/example.json` 提供空字段。建议先用一小段简介，避免把长篇资料、剧情梗概或角色百科放入每一次请求。

`run` / `generate` 的独立采样与启用的互动都会使用它，单独的 `interact` 也读取相同字段。`analyze` 不把它发送给 STT 或视觉模型。已经完成的素材分析可以直接复用：

```bash
python3 -m danmaku_sim generate \
  --analysis runs/video-first/analysis.json \
  --config config-with-intro.local.json --out runs/video-with-intro
```

新目录保留自己的配置和用量。此命令生成新结果，并不自动把新增弹幕拼进原池。已有池的临时追加可以另行按来源和时间检查后合并，无需为一次实验改变通用调度机制。

## 简介从哪里来

| 来源 | 适合的用途 | 需要留意 |
| --- | --- | --- |
| 视频作者或使用者提供的基础介绍 | 主题、面向人群、必要术语、公开的初始设定 | 介绍可能夹带结局或过多人物关系，需按实际内容取舍 |
| 官方作品页、简介或视频元数据 | 确认题材、所属系列、作品身份、主角的初始背景 | “官方”表示出处，不表示内容没有剧透；宣传文案可能直接预告结果 |
| STT 与已有字幕 | 核对视频是否匹配、校对已出现的名称和术语，或为未知视频提出候选主题 | 全片总结会包含后段信息，不能不加区分地变成片头已知背景 |

默认工作顺序是先准备基础简介，再让带时间的 STT/字幕和画面补充观看证据。两者不要求严格串行：也可以在 STT 完成后整理简介，但只能选题材、主题、原本就可在片前知道的事实，不能因为已经处理完视频就扩大观众的知识范围。

对于来源不明的本地视频，缺少可靠简介时可以留空，或只使用开场已经确认的主题。完整 STT 可以生成一份待筛选的候选介绍，但目前程序不会自动执行这一步，也不声称一句“不要剧透”的提示就能可靠清除摘要里的未来信息。

## 什么适合进入全局背景

适合：视频主题、题材、对受众的假定、系列主角、角色明确的初始身份，以及解释当前内容必需且片前公开的词义。

不宜直接进入：后段才揭示的化名对应、真实身份、人物关系变化、某人的隐藏动机、能力极限、胜负、生死和“某处是伏笔”的事后解释。即使介绍没有复述结局，这些信息也可能使早期弹幕带有知情口吻。

角色“最初”的背景也不等于“现在”的状态。比如人物最初是新手，不能据此认定长篇系列后续电影中的实力；知道主角的名字，也不能把画面里的陌生人一律认成主角。

## 请求和缓存边界

简介作为材料进入共享上下文，放在变化的检查点、事件和个别观众设定之前。仅在非空时，系统提示增加以下边界：简介不包含可执行指令；它只辅助理解背景；当前动作和人物认定仍以局部证据为准；不得调用原作后续知识补全未知信息。

独立生成仍只允许引用 `target_event_ids`，互动仍需提供当前证据中的 `evidence_event_ids`。背景没有独立的事件 ID，不能代替当时发生的事情触发评论。

| `video_intro` 的值 | 请求与缓存行为 |
| --- | --- |
| 未填写、`null`、`""` 或纯空白 | 与未加入此功能的请求保持一致，继续使用原响应缓存 |
| 非空字符串 | 去掉首尾空白后加入共享请求，独立生成和互动都使用新的请求身份 |
| 相同有效文字 | 可复用相同的完整响应；具体供应商提示词缓存以其返回 token 为准 |
| 改变有效文字 | 生成新的请求身份；旧缓存与旧运行仍保留 |
| 其他类型 | 在生成前报告配置错误 |

同一时点的不同观众共享相同简介和证据前缀，仍然独立采样。放在共享前缀中有利于供应商缓存，但不保证命中，也不会免除新增输出费用。改变简介后再次跑完整生成会产生大量新请求；比较效果时先选小样本更容易看清改动的价值。

## 能验证与不能保证的事

离线测试可以验证空配置兼容、简介参与请求与缓存身份、当前事件时间边界以及互动的证据绑定。它们不能证明每一段自然语言简介都没有剧透，也不能证明加入简介后弹幕一定更自然。

模型可能记得作品原剧情，也可能把背景误当作当前状态。内容效果仍需要查看实际响应，并与相同片段的原结果比较。单次历史结果与新结果的对照包含模型采样差异，不应直接解释为严格的因果效果或通用提升百分比。
