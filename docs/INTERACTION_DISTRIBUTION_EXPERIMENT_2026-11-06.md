# 少量互动与分发：2026-11-06 实测

本轮在上一轮 52.208333 秒 Sintel 样例上追加互动，并把结果发布为本地/远端都能读取的静态轨道。原始样例和成本口径见[首次实验报告](EXPERIMENT_2026-11-06.md)。

## 实际新增的互动

保留原来的 63 条独立弹幕与 2 条受控复读，新增 **3 条接话**，总数 68。每条接话来自另一 persona 的独立请求，读取该父弹幕和当时已经可知的证据。

| 前一条弹幕及出现时间 | 接话及出现时间 | 间隔 |
| --- | --- | ---: |
| 6.367 秒：好冷的样子，这得穿多厚啊 | 8.509 秒：这毛边看着就很厚 | 2.142 秒 |
| 19.938 秒：雪地这些黑点是什么？ | 20.702 秒：看着像污渍 | 0.764 秒 |
| 33.031 秒：这小红翅膀是龙吗？ | 33.818 秒：像，但还不太确定 | 0.787 秒 |

这些是实际模型输出，未人工重写。最后一条保留了上游视觉观察的不确定性。接话关系已经形成，但口语感仍有改进空间，不能仅凭三个样本证明观看真实性显著提高。

配置为独立弹幕数的 6% 预算、最多 4 条，向下取整后本例计划 3 次调用。每个父弹幕和源事件最多一次、只接一层、两次互动至少相距 8 秒。先在已有全部弹幕占位中查找合法空隙，再请求模型；有 33 个候选因密度或间隔不合适被跳过，没有为它们付费。

这批回复恰好都由 MiniMax M3.1 Flash 生成，是配置权重与固定 seed 的选择结果，不代表比较了不同模型的互动质量。此前独立观众仍包含两个模型。

费用全部属于订阅渠道的按量参考折算，实际扣款仍未知。没有重新调用 STT、视觉模型或原 63 次观众生成。新 run 的账本只包含互动，预览页明确标注“本次新增互动参考费”，原轨道费用没有重复计入。

在前一轮包含一份 STT 的 $0.01699031 参考成本上加入这批互动，总参考成本为 $0.01757360。它只代表当前短样本与价格快照。

公开的去标识账本、参数和实际输出在 [examples/sintel/social](../examples/sintel/social/)。`experiment.json` 保留首次执行结果，`usage-summary.json` 还包括下面的本地复用验证。

## 完整结果缓存与旧内容保留

随后从同一基础 run 重新执行 `interact`。验证时监测并禁止网络入口，得到：

- 新增 3 次本地结果复用，网络尝试为 0；累计真实请求仍为 3。
- 累计参考成本保持 $0.00058329，不增加输入/输出 token。
- 68 条最终弹幕与首次结果完全相同。
- 原 65 条的完整记录、文字、时间和身份均未改变。
- 本次缓存复用执行耗时 0.026 秒。

证据见 [cache-replay.json](../examples/sintel/social/cache-replay.json)。仓库没有分发原始响应缓存；别人回放已生成轨道无需模型，重新生成仍需要自己的模型配置和调用。

## 已发布的轨道

| 轨道 | JSON | XML | ASS | 弹幕数 |
| --- | ---: | ---: | ---: | ---: |
| standard | 23,147 字节 | 6,381 字节 | 9,687 字节 | 65 |
| social | 24,908 字节 | 6,632 字节 | 10,073 字节 | 68 |

每个版本的文件有实际字节摘要，catalog 使用相对路径；源视频、原始分析、配置和用量不进入轨道文件。同一目录可本地读取或通过静态 HTTP 提供。公开 HTTPS 样例是 [examples/catalog](../examples/catalog/) 中的小型固定样本，真实个人弹幕库仍独立存放。

`publish` 重复执行可复用完全相同的版本；新内容产生新路径。XML/ASS 应用时间映射后生成，JSON 保留源时间和映射。默认服务仍能做本地实验预览；`--catalog-only` 模式只允许读取已发布目录，原始运行和媒体路由关闭。

## 网页与电视的验收边界

网页用户脚本的浏览器、全屏、导入、SPA 和实际站点记录见 [clients/browser/README.md](../clients/browser/README.md)。脚本管理器权限与本地模拟接口应分别记录，不能把测试桥接当作已经安装真实扩展。

电视侧基于既有 MzDKPlayer-NAS 的 HTTPS WebDAV + 同名 XML 成功路线，新增 `sidecar` 导出已做文件与命名规则验证。实际导出的 `sintel-trailer.xml` 含 68 条，逐字节等于目录里的 social XML；[校验记录](../examples/sintel/social/sidecar-check.json)保留文件摘要。本轮没有选择新电视片源、部署 NAS 或操作盒子，因此不声称这批生成弹幕已经在电视上播放。具体来源与后续接入见[电视适配说明](TV_PLAYER_ADAPTER.md)。
